SiloV / Overview

A workspace for technical documentation

Create, review, and export visual HTML, Markdown, XML, and DITA documents in your browser. Use the documentation for workflows, format limits, and worked writing examples.

Open workspaceRead documentation

How SiloV is organized

Writing workspace
Author visual HTML, Markdown, XML, and scoped DITA topics; check and export documents. Documents are stored in this browser.
Documentation examples
Finished writing samples bundled with the site: a tutorial, API reference, troubleshooting guide, and how-to.
Optional local API
Read and add entries to the sample collection’s JSON file in a local checkout. It does not edit the full sample articles or publish changes.

Repository map

Path Purpose
workspace.html, workspace.css Writing interface
scripts/workspace/ Editor, storage, templates, rendering, and review
documentation.html, samples.html Documentation hub and full writing examples
posts/posts.json, scripts/app.js Example metadata and browser search
backend/src/ Optional Express API and JSON storage helpers
tests/, backend/test/ Model, browser, and API tests
docs/, SECURITY.md Technical notes and security boundaries

Run locally

git clone https://github.com/timedilationv2/silov0.git
cd silov0
python3 -m http.server 8000 --bind 127.0.0.1

Open http://localhost:8000/. Python 3 is enough to serve the site; browser libraries are bundled. No build, account, API key, or running backend is needed.
