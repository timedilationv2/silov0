Writing workspace and documentation

SiloV combines a browser-based Markdown editor, a searchable collection of documentation examples, and a local API for managing the sample collection.

Open workspaceRead documentation

Three components

Writing workspace
Draft, preview, check, and export documents. Documents are stored in this browser.
Documentation examples
Finished writing samples bundled with the site: a tutorial, API reference, troubleshooting guide, and how-to.
Optional local API
Read and add entries to the sample collection’s JSON file in a local checkout. It does not edit the full sample articles or publish changes.

Run locally

git clone https://github.com/timedilationv2/silov0.git
cd silov0
python3 -m http.server 8000 --bind 127.0.0.1

Open http://localhost:8000/. Python 3 is enough to serve the site; browser libraries are bundled. No build, account, API key, or running backend is needed.
