Structured AI news feed exposed as JSON resources, rendered into a live demo on this page.

Sample project · local API + static demo

Overview

silov0 packages quick AI news drops, release notes, and applied takeaways into a structured stream. This static site stands in for the API surface that would normally power a client feed.

Everything is stored in posts/posts.json and rendered as cards and tables. Treat it as a developer-friendly mirror of a lightweight publishing backend.

Authentication

The static demo and local API have no authentication. Run the API locally; it permits writes and is not configured as a public publishing service.

Resources & endpoints

The demo reads posts/posts.json. Run the separate API with cd backend && npm ci && npm run dev (Node 18+).

GET /api/posts

Returns a JSON array of all posts, newest first. Query parameters on this route do not filter results.

GET /api/posts/filter

Use ?tag=ai&q=digest. The tag match is exact and case-sensitive; text search is case-insensitive across title, summary, and tags. Both conditions must match. No results returns [].

POST /api/posts

Send a JSON object with a non-empty title and a real date in YYYY-MM-DD format. Optional fields: id, summary, url (strings), and tags (an array of non-empty strings). An omitted id is generated from the date and title. Returns status 201 and the full updated array.

Errors use {"error":"message"}: 400 for invalid input or JSON, 409 for duplicate IDs, 404 for unknown routes, and 500 for server failures. GET /health returns {"ok":true}.

Filtering

The browser filters the static JSON in memory. Try searching for digest or selecting web. The local API equivalent is /api/posts/filter?tag=ai&q=digest. There is no pagination, single-post route, or tags endpoint.
