Setup

git clone https://github.com/timedilationv2/silov0.git
cd silov0
python3 -m http.server 8000 --bind 127.0.0.1

Open http://localhost:8000/. Python 3 is enough to serve the site; browser libraries are bundled. No build, account, API key, or running backend is needed.

Use HTTP rather than opening a file directly. Keep credentials outside the served directory. Stop the server with Ctrl+C. The local API is optional and is not part of GitHub Pages.

Architecture and data storage

The workspace controller in scripts/workspace/app.mjs composes the model, storage, templates, editor adapters, Markdown rendering, review, and XML/DITA validation modules. Tiptap/ProseMirror powers visual editing; CodeMirror powers source editing. Marked parses Markdown; DOMPurify sanitizes rendering and HTML imports. Local vendor files avoid third-party requests. The workspace policy permits same-origin assets/workers, WASM, and data-URL images while blocking remote images and active embeds.

Documents use the existing IndexedDB database silov0-workspace, version 2, object store documents, with originals archived in legacy-v1. Records contain id, title, content, collection, creation/modification timestamps, revision, format, schema version, and optional schema/template/original-source metadata. Theme, view, and last selected document use optional localStorage preferences. The v2 upgrade archives original v1 records without rewriting them; old documents open as Markdown. Navigation uses the same database and origin. See editor formats and validation limits.

Autosave is debounced by 450 ms. Transaction completion marks a save successful; revision checks reject stale saves from another tab. A failed restore transaction rolls back its batch. See backup and recovery guidance.

The documentation search fetches posts/posts.json directly. Entries describe and link to full articles in samples.html; a JSON entry is not an article body. Express reads and adds entries in that file in a local checkout using locked writes and atomic replacement. It caches reads; restart it after manual file edits. Neither API writes nor workspace edits publish anything. Source changes must be reviewed, merged, and deployed separately.

Development and tests

Node 20+ is required at the root; the separate backend supports Node 18+. No runtime compilation step is needed. Run npm run vendor after changing editor dependencies to regenerate the checked-in browser bundle and XML validator assets. 

npm ci
npm test
cd backend
npm ci
npm test
cd ..
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/workspace_browser.py
# With the static server running:
python3 tests/demo_smoke.py http://localhost:8000/
python3 tests/security_browser.py http://localhost:8000/
python3 tests/site_browser.py http://localhost:8000/

Model tests validate templates, backups, and review findings. Backend tests cover API responses, authentication, validation, concurrency, and storage failures. Browser tests cover persistence, editing, recovery, exports, sample search, navigation, responsive layouts, and XSS regressions. Chromium needs its platform libraries. Use SILOV_CHROMIUM_EXECUTABLE=/usr/bin/chromium with the browser tests to select an already installed system browser.
